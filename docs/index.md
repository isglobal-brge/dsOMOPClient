# Learn dsOMOPClient

Build study tables while patient records stay on each server. This book
teaches the recipe API with **dsOMOP 2.10.5**, on synthetic GiBleed,
Synthea and questionnaire data. Every chapter has executed examples,
real outputs and at least three exercises with collapsible solutions.

[Explore what you can do
→](https://isglobal-brge.github.io/dsOMOPClient/articles/book-showcase.md)

## Tutorial chapters

The numbered tutorial runs from first connection through native numbers
and reproducibility to the cause-of-death capstone. The case studies
then combine those skills into end-to-end studies. Dataset and API
limitations are shown explicitly where a requested analysis cannot be
supported.
