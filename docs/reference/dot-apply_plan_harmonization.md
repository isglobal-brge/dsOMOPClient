# Inject data-independent federation settings into a plan

Baseline age groups are materialized on each server. When local public
age grids differ, send their negotiated common coarsening so every site
emits the same labels instead of rejecting an otherwise compatible
analysis.

## Usage

``` r
.apply_plan_harmonization(plan, contract)
```

## Arguments

- plan:

  Extraction plan.

- contract:

  Compatible federation contract.

## Value

The plan with common age breaks attached where required.
