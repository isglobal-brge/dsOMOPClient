# Format a concept label for filter display (vector-safe)

Format a concept label for filter display (vector-safe)

## Usage

``` r
.concept_label(concept_id, concept_name = NULL)
```

## Arguments

  - concept\_id:

    Integer scalar or vector of concept IDs

  - concept\_name:

    Character or NULL; human-readable name(s)

## Value

Character scalar suitable for a filter label
