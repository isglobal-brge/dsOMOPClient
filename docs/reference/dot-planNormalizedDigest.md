# Semantic digest of a version-2 plan over its normal form

Semantic digest of a version-2 plan over its normal form

## Usage

``` r
.planNormalizedDigest(plan, schema = NULL)
```

## Arguments

  - plan:

    A version-2 plan.

  - schema:

    Optional parsed plan-v2 schema.

## Value

\`list(payload, sha256)\` as returned by \`.planSemanticDigest()\`.
