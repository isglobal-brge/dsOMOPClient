# Semantic digest of a normalised plan IR

Semantic digest of a normalised plan IR

## Usage

``` r
.planSemanticDigest(ir)
```

## Arguments

  - ir:

    The normalised IR (named list as parsed with simplifyVector = FALSE,
    or the identical structure built in R).

## Value

A list with \`payload\` (canonical JSON) and \`sha256\` (hex).
