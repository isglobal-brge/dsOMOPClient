# Refusal of an execution that needs the publication protocol on old sites

Refusal of an execution that needs the publication protocol on old sites

## Usage

``` r
.plan_protocol_refusal(route, what = "A language-2 plan", v1_refusal = NULL)
```

## Arguments

  - route:

    A `.plan_protocol_route()` result.

  - what:

    What needs the protocol.

  - v1\_refusal:

    Why a newly permitted shape has no v1 plan, or NULL.

## Value

A character message.
