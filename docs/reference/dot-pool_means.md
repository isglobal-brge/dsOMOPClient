# Pool means weighted by count

Pool means weighted by count

## Usage

``` r
.pool_means(per_site_means, per_site_counts, policy = "strict")
```

## Arguments

- per_site_means:

  Named numeric vector of means

- per_site_counts:

  Named numeric vector of counts (same names)

- policy:

  Character; pooling policy

## Value

List with \$result and \$warnings
