# Pool proportions weighted by denominator

Pool proportions weighted by denominator

## Usage

``` r
.pool_proportions(per_site_num, per_site_denom, policy = "strict")
```

## Arguments

- per_site_num:

  Named numeric vector of numerators

- per_site_denom:

  Named numeric vector of denominators

- policy:

  Character; pooling policy

## Value

List with \$result and \$warnings
