# The plan a recipe executes as on the connected servers

`.recipe_select_plan()`, then, for a v2 plan, every site must publish
the publication protocol (`.plan_protocol_route()`) and advertise recipe
language 2 and the operations the plan needs; a recipe selected for a
newly permitted shape is refused naming its v1 refusal and the older
server. A v1 plan needs neither (the executor chooses its call).

## Usage

``` r
.recipe_plan_for_execution(
  recipe,
  session,
  conns,
  plan = .recipe_select_plan(recipe),
  server_method = "omopPlanExecuteDS"
)
```
