# Domain concept column of an event table, from the role registry

Domain concept column of an event table, from the role registry

## Usage

``` r
.role_domain_concept(table)
```

## Arguments

  - table:

    Table name (case-insensitive), or NULL.

## Value

The domain concept column (CDM 5.4 record first, then 5.3), or NULL when
the table is unknown or has none.
