# The language-2 event a legacy variable reads

The language-2 event a legacy variable reads

## Usage

``` r
.v2_legacy_variable_event(v, context)
```

## Arguments

  - v:

    A legacy `omop_variable` (table/format spelling).

  - context:

    Character; error context.

## Value

An `omop_event` object (unnamed; interned by the compiler).
