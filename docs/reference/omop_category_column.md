# Copy a categorical output column before presentation

Copy a categorical output column before presentation

## Usage

``` r
omop_category_column(column, component = NULL, category_spec = NULL)
```

## Arguments

  - column:
    
    Stable original column key.

  - component:
    
    Exact component for outputs with multiple row frames.

  - category\_spec:
    
    Independent category presentation.

## Value

A row-preserving output-local variable declaration.
