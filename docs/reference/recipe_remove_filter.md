# Remove a filter from the recipe

Removes a filter by its ID from the recipe's filter list.

## Usage

``` r
recipe_remove_filter(recipe, id)
```

## Arguments

- recipe:

  An `omop_recipe` object.

- id:

  Character; filter ID to remove.

## Value

The modified `omop_recipe` object.
